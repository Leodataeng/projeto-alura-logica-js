## 📌 Sobre o Projeto
Este é um projeto prático desenvolvido durante o curso de **Lógica de Programação** da Alura. 

O objetivo principal deste repositório não é o desenvolvimento web em si, mas a construção e consolidação do raciocínio lógico, criação de algoritmos e manipulação de variáveis. Essa base estrutural é o alicerce fundamental para a escrita de scripts eficientes e processos de automação na área de Engenharia de Dados.

## ⚙️ Conceitos Técnicos Aplicados

Durante o desenvolvimento do "Jogo do Número Secreto", as seguintes competências lógicas foram exercitadas:

* **Estruturas de Controle de Fluxo:** Utilização intensiva de condicionais (`if/else`) para validação das tentativas do usuário e direcionamento das respostas do jogo.
* **Manipulação de Arrays (Listas):** Criação de uma lógica de armazenamento em listas para garantir que os números secretos não sejam repetidos na mesma rodada, controlando o estado da aplicação.
* **Funções e Escopo:** Modularização do código através de funções (`gerarNumeroAleatorio`, `verificarChute`, `limparCampo`) para evitar repetição, mantendo o código limpo e sustentável.
* **Operadores Lógicos e Matemáticos:** Uso da biblioteca `Math` para geração de dados aleatórios e operações de validação.

## 🚀 Como testar o código

1. Faça o clone ou o download deste repositório.
2. Abra o arquivo `index.html` diretamente em qualquer navegador web.
3. Insira os números para interagir com a lógica condicional do jogo.
